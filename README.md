# 법무 채용 레이더

사람인·잡코리아·인크루트에 올라온 **법무·컴플라이언스·특허·감사** 채용공고를 매일 모아 보여주는 사이트입니다.

## 기능

- **공고 모아보기**: 분야(법무·컴플라이언스·특허·감사)와 세부 직무 16개, 사이트, 등록일, 마감, 경력, 지역, 학력, 고용형태로 바로 걸러 봅니다. 조건은 링크로 공유할 수 있습니다.
- **기업정보**: 공고를 낸 기업의 평균연봉, 사원 수, 매출액, 업력을 카드에 함께 보여줍니다 (사람인 기업정보 기준).
- **캘린더**: 마감일을 달력으로 봅니다. 관심공고만 볼 수도 있습니다.
- **지원 현황**: 관심 → 지원 완료 → 서류 합격 → 면접 → 결과로 칸반 관리하고 메모를 남깁니다.
- **저장한 검색**: 조건을 저장해두면 다음 방문 때 새로 발견된 공고 수를 알려줍니다.

관심공고, 지원 현황, 메모, 저장한 검색은 각자의 브라우저에만 저장됩니다.

## 구조

| 경로 | 내용 |
|---|---|
| `page.html` | 페이지 원본 (스타일과 스크립트 포함) |
| `index.html` | `scripts/build_page.py`가 `page.html`로 만든 배포용 파일 |
| `data/jobs.json` | 공고 데이터 |
| `data/companies.json` | 기업정보 데이터 |
| `scripts/collect.py` | 공고 수집기 |
| `scripts/companies.py` | 기업정보 수집기 |
| `scripts/check.py` | 수집 결과 점검 (공고 급감이나 사이트 0건이면 반영하지 않음) |
| `.github/workflows/refresh.yml` | 매일 06:47(한국 시간) 수집 후 `data/`를 커밋 → Vercel이 자동 배포 |

페이지를 고친 뒤에는 `python3 scripts/build_page.py`로 `index.html`을 다시 만듭니다.

## 데이터 수집 원칙

- 각 사이트 robots.txt가 허용하는 **공개 검색 목록**과 기업정보 경로만 사용합니다.
- 공고의 **요약 정보**(제목, 회사, 지역, 경력, 학력, 고용형태, 등록일, 마감일)와 **원문 링크**만 저장합니다. 상세 본문은 저장하지 않으며, 지원과 상세 확인은 원문 사이트에서 합니다.
- 요청 사이에 간격을 두고, 수집 프로그램 이름(`LegalComplianceJobsBot`)과 이 저장소 주소를 밝혀 접속합니다.
- 공개 서비스로 규모를 키우기 전에 각 사이트 이용약관 확인이나 제휴(공식 API)를 권장합니다.
